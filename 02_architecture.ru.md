# Архитектура системы и процессорный кластер модуля ADP201P4

Внутренняя архитектура модуля **ADP201P4** представляет собой высокопроизводительный вычислительный кластер из нескольких сигнальных процессоров, интегрированных с быстрой локальной памятью и специализированными путями маршрутизации данных на базе ПЛИС.

## 🖥️ Процессорный кластер ЦПОС и карта памяти

На плате размещены **четыре независимых процессора цифровой обработки сигналов ADSP-TS201S (TigerSHARC)** с тактовой частотой **500 / 600 МГц**, объединенные в единую распределенную сеть:
* **Локальная оперативная память:** Каждый процессор (от P1 до P4) оснащен выделенным банком памяти **SDRAM объемом 16Mx64** для выполнения алгоритмов фильтрации и обработки сигналов в реальном времени.
* **Энергонезависимая загрузочная память:** Общая Flash-память **объемом 4Mx8** подключена напрямую к адресному пространству **Процессора 1 (P1)**.
* **Межмодульные связи:** Каждый процессор выводит ровно по одному внешнему линк-порту TigerSHARC на внешние разъемы платы (**1-Link3, 2-Link3, 3-Link3 и 4-Link3**), что позволяет каскадировать модули в общую сеть.

## 🔀 Интерфейс связи с управляющей ЭВМ (HOST)

Передача потоков данных между процессорным кластером и системной шиной PCI главного компьютера осуществляется через многоступенчатый аппаратный тракт:

1. **Контроллер шины PCI:** Отвечает за физическое сопряжение и выполнение протокола обмена с PCI-шиной управляющего ПК.
2. **ПЛИС HOST:** Выступает главным диспетчером данных на плате и содержит глубокие аппаратные буферы для развязки высокоскоростных операций ЦПОС от задержек системной шины ПК:
   * **DPRAM (4096x32):** Двухпортовое ОЗУ для быстрого обмена регистрами управления и флагами состояний.
   * **FIFO 1 и FIFO 2 (по 1024x32 каждое):** Два независимых однонаправленных буфера аппаратных очередей, которые транслируют блоки отсчетов АЦП/ЦАП в память компьютера.
3. **Межсоединение кластера:** ПЛИС HOST общается с процессорным кластером через выделенный линк-порт, подключенный напрямую к **Процессору 1 (интерфейс 1-Link0)**.
