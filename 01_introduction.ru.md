# Введение и семейство модулей ADP201

На странице собраны соглашения об обозначениях, основные термины и сведения о семействе ADP201 из руководства ADP201P4 **СКУЮ.467459.033 РЭ**.

## Соглашения об обозначениях

- Шестнадцатеричные значения имеют префикс 0x (например, 0x0 и 0xFFFF).
- Битовые поля регистров записываются в форме РЕГИСТР[ПОЛЕ]. Примеры из руководства: CSR[GIE], HPIA[31:2] и 0x01940000[2].

## Основные термины

- **Базовый модуль:** плата, на которую устанавливается дочерняя плата (субмодуль).
- **Субмодуль:** плата, устанавливаемая на базовый модуль.
- **Процессор ЦОС:** сигнальный процессор модуля.
- **Тетрада:** группа из четырёх регистров, реализованных в ПЛИС ADM.
- **Блок регистров:** группа из 32 регистров, реализованных в ПЛИС HOST.
- **'TS201:** сокращённое обозначение ADSP-TS201S, используемое в руководстве.
- **Главная ПЭВМ / HOST PC:** компьютер, в который установлен модуль ЦОС.

## Отличия ADP201P4 от ADP201PCI

В руководстве перечислены четыре отличия, важные при переносе ПО и проектировании систем:

1. В ADP201P4 отсутствует узел ЦАП.
2. P1 подключён к ПЛИС HOST, P2 — к ПЛИС ADM.
3. На плате установлены четыре банка SDRAM по 128 Мбайт, по одному на процессор.
4. Шина PCI имеет разрядность 64 бита.
