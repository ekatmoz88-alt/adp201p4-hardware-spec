## 📌 Краткое описание

**ADP201P4** — это высокопроизводительный многопроцессорный базовый модуль (плата-носитель) для шины PCI, предназначенный для скоростного сбора, синтеза и цифровой обработки сигналов. Построен на базе кластера из четырех сигнальных процессоров **Analog Devices ADSP-TS201S (TigerSHARC)** и оснащен прогрессивным мезонинным интерфейсом **ADMPRO** для установки дочерних субмодулей (АЦП/ЦАП).

Плата оптимизирована для жесткой межмодульной синхронизации, что позволяет объединять несколько модулей в единую распределенную вычислительную сеть для задач радиолокации, связи и программно-определяемого радио (SDR).

---

## 🏗️ Архитектура и аппаратные особенности

### 🖥️ Вычислительный кластер
* **ЦПОС:** 4 независимых процессора ADSP-TS201S (TigerSHARC) с тактовой частотой **500 / 600 МГц**.
* **Память:** Выделенные банки **16Mx64 SDRAM** для каждого процессора.
* **Энергонезависимая память:** Общая память **4Mx8 Flash**, подключенная к процессору P1.
* **Межпроцессорный обмен:** Процессоры объединены внутри платы через высокоскоростные линк-порты.

### 🎛️ Мезонинный интерфейс ADMPRO
* **Управляющее ядро:** ПЛИС **Xilinx Spartan-3** (`XC3S400` или `XC3S1500`).
* **Локальная память ПЛИС:** Быстрая статическая память **2Mx18 SSRAM / SBSRAM**.
* **Связь с ПК:** Буферизация данных через специализированную **ПЛИС HOST** (двухпортовая ОЗУ `DPRAM 4096x32` и очереди `FIFO 1024x32`) для минимизации задержек шины PCI.
