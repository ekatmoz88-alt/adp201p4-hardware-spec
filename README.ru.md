# Модуль обработки сигналов ADP201P4

Структурированная техническая документация по модулю ADP201P4 на основе руководства **«Модуль процессора обработки сигналов ADP201P4. Техническое описание и руководство по эксплуатации»**, документ **СКУЮ.467459.033 РЭ**.

[English version](./README.md)

## Назначение модуля

ADP201P4 — модуль цифровой обработки сигналов с интерфейсом PCI, построенный на четырёх процессорах Analog Devices **ADSP-TS201S (TigerSHARC)**. В руководстве описаны сбор и цифровая обработка сигналов, подключение мезонинных субмодулей через интерфейс **ADMPRO** и взаимодействие с другими модулями семейства ADP201.

## Подтверждённые характеристики

- **Процессоры:** 4 × ADSP-TS201S; варианты тактовой частоты 500 и 600 МГц.
- **Тактовая частота системной шины:** 100 МГц.
- **Оперативная память:** четыре отдельных банка SDRAM по 128 Мбайт — по одному на процессор.
- **FLASH:** в таблице технических данных указано 4 Мбайт; в описании процессорного узла приведён диапазон 2–4 Мбайт. Конкретную конфигурацию следует проверять для соответствующей платы.
- **Интерфейс HOST:** PCI, 64 разряда, 66 МГц.
- **Внешние линк-порты TigerSHARC:** четыре, по одному от каждого процессора.
- **Интерфейс ADMPRO / ПЛИС ADM:** управляется ПЛИС Xilinx Spartan-3 XC3S400-5FG456 или XC3S1500-5FG456.
- **PIOX:** 16-разрядный интерфейс LVTTL или 8-разрядный LVDS — в зависимости от исполнения платы.

## Границы описания и примечания к источнику

В документации отделены сведения, прямо приведённые в руководстве ADP201P4, от деталей, для проверки которых требуются сопутствующие документы, спецификации прошивок, данные о ревизии платы или аппаратная проверка. Руководство не подтверждает универсальную топологию mesh для линк-портов DSP и не содержит достаточных данных для указания конкретных ёмкостей SSRAM, DPRAM или FIFO, универсальной карты регистров ПЛИС HOST либо конфигурации опциональной памяти. Не предполагаются конкретная модель субмодуля ADM или реализация прошивки.

В исходном руководстве встречаются отдельные несогласованности в обозначениях и редакционные ошибки. Они не исправляются молча, если могут повлиять на технический смысл. Этот пример портфолио представляет собой переработанную структурированную документацию, а не копию исходного руководства.
